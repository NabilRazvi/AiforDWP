# Self-Service Answers for Top 3 Themes

## 1) Authentication lockouts and AVD sign-in failures
Please try these steps:
1. Close all sign-in windows, then sign in once more using your full work email and your latest password.
2. If it still fails, restart your device and try again after 2 minutes.

If you still cannot sign in, contact the Service Desk right away and share: your username, exact error message on screen, time of last failed attempt, and whether this is for AVD, laptop sign-in, or both.

## 2) Missing files and OneDrive sync concerns
Please try these steps:
1. Open OneDrive, check if it says signed in, and click Sync now (or Resume syncing) if shown.
2. Search OneDrive on the web for the missing file name to confirm whether it exists there.

If files are still missing, contact the Service Desk and share: file names, folder paths, last time you saw the files, and a screenshot of any OneDrive warning message.

## 3) Shared drive access denied (S:/Finance)
Please try these steps:
1. Disconnect and reconnect to VPN, then open File Explorer and try the S: drive again.
2. If S: still fails, restart your device once and retry access.

If access is still denied, contact the Service Desk and share: your department/team, drive name (S:), exact error text, time of failure, and whether coworkers can access the same folder.
