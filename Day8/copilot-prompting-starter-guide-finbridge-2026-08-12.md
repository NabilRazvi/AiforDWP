# Copilot Prompting Starter Guide (FinBridge)

This guide is for non-technical office staff who want better results from Microsoft 365 Copilot in day-to-day work.

The quickest way to improve Copilot responses is to give it a little context, a clear task, and the format you want back.

## The 10-Second Prompt Formula

Use this simple formula every time:

**Role + Context + Task + Output + Checks**

Think of it like this:

- **Role:** Who Copilot should act as
- **Context:** What this is about
- **Task:** What you want it to do
- **Output:** The format, tone, and length
- **Checks:** Anything important to include or avoid

Template you can copy:

> Act as a [role]. Using [context], [task]. Return it as [output format, tone, length]. Make sure to [checks].

Example:

> Act as a professional customer support assistant. Using my draft below, rewrite it to explain a delayed payment update. Return a short email in a friendly, clear tone (under 140 words). Make sure it includes an apology, expected date, and a clear next step.

## Outlook: Real Prompt Examples

Use these directly in Outlook Copilot and edit names/dates.

### 1) Turn rough notes into a clear client update

> Draft an email to Sarah Patel at Northgate Retail. Context: we are running 2 business days late on their invoice check because some invoice numbers did not match and needed rechecking. Output: professional but warm, 120-160 words. Include: apology, current status, new expected completion date (Friday 16 Aug), and one clear next step for the client.

### 2) Summarise a long email thread before replying

> Review this email thread and give me: 1) a 5-bullet summary, 2) open questions still unresolved, and 3) a suggested reply I can send. Tone: calm and helpful. Keep the reply under 130 words and include a proposed meeting time next week.

### 3) Write a follow-up after no response

> Draft a polite follow-up email to James Wood about the contract addendum sent on 5 Aug. Goal: get confirmation by end of week. Tone: friendly, not pushy. Output: subject line + email body, under 110 words. Include a simple call to action and offer a 15-minute call.

## Word: Real Prompt Examples

Use these in Word when drafting or improving documents.

### 1) Convert meeting notes into a formal summary

> Turn the notes below into a one-page meeting summary for internal stakeholders. Structure it with headings: Decisions, Risks, Actions, Owners, Dates. Keep the language plain and direct. Do not add information that is not in my notes.

### 2) Rewrite for plain English

> Rewrite this policy paragraph for non-technical office staff. Keep the meaning exactly the same, reduce jargon, and keep each sentence under 20 words where possible. Return: original vs rewritten so I can compare.

### 3) Build a first draft from bullet points

> Create a first draft memo for Finance Operations based on these bullet points. Audience: busy managers. Tone: clear and practical. Output sections: Purpose, Current Issue, Recommended Approach, Timeline, Risks, Request for Approval. Keep it under 700 words.

## Excel: Real Prompt Examples

Use these in Excel Copilot for analysis and reporting help.

### 1) Quick insight summary from a table

> Look at the table in this sheet and give me the top 5 takeaways in plain English for a weekly operations update. Focus on patterns, unusual numbers, and any sudden changes from last month. Output: short bullet points that a manager can read in 1 minute.

### 2) Explain what changed month-to-month

> Compare July vs August values in this workbook for each region. Show which regions improved, which declined, and by what percentage. Return a concise summary paragraph plus a table with Region, July, August, % Change, and Status (Up/Down/Flat).

### 3) Help me build a useful formula

> I need to flag rows where invoice amount is over 10000 and payment status is Overdue. Suggest the exact Excel formula for a new column called Risk Flag, then explain in one sentence how it works. Also provide a second version that handles blank cells safely.

## Prompt Upgrade Tips (When Results Are Too Vague)

If Copilot gives a generic answer, add one or two of these:

- Add audience: "for a client", "for senior managers", "for new starters"
- Add limits: "under 120 words", "5 bullets max", "table with 4 columns"
- Add intent: "so they can decide today", "so I can send this as-is"
- Add checks: "do not invent facts", "highlight missing information"

Quick fixer prompt:

> Improve your previous response by making it more specific to Finance Operations. Keep it under 100 words and include one clear recommendation.

## Data Safety Reminder (Day 1 Habit)

From Day 1 of this programme, the habit is simple:

**Treat sensitive data carefully every time you prompt.**

- You can use Microsoft 365 Copilot confidently for everyday work inside approved FinBridge tools.
- Keep the Day 1 habit: do **not** paste confidential client data into external AI tools (public chatbots or unapproved websites/apps).
- If you are unsure, pause and check with your manager or Information Security before sharing the data.

A safe working practice is to remove identifying details where possible (for example: client names, account numbers, personal identifiers), unless the task must use approved internal systems.

## A 30-Second Prompt Checklist

Before you press Enter, check:

- Did I give enough context?
- Did I ask for a clear output format?
- Did I set tone/length/audience?
- Did I include key checks (accuracy, no invented facts)?
- Am I following the Day 1 data-safety habit?

If yes, send it. If not, add one line and try again.
